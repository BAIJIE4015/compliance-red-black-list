分级体系与状态流转

四级榜单结构、统一状态枚举与流转规则、数据字段设计 —— 对外展示的四级榜单由统一状态枚举映射得到

四级榜单

所有场景统一采用四级榜单结构，便于跨场景对比与首页导航

分级 含义 处理方式
红榜 合规、可信、可推荐，证据充分 可公开推荐
观察名单 存在争议或风险，但证据不足 仅提示风险，不下结论
灰名单 已提交初步证据，处于待考证 / 待自证 / 待核验状态 标注「未证实」，限制传播，启动核验，可申诉
黑名单 已有行政处罚、法院判决、监管通报或可靠第三方报告 可正式列入，附来源链接与结论摘要

状态枚举与流转规则

程序层统一状态枚举：red / watch / gray_unverified / gray_self_proof / blacklisted / appealing / revoked

提交线索 → gray_unverified（待考证） → gray_self_proof（待自证） → blacklisted（黑名单）/ red（红榜）

分支流转：gray_self_proof 核验不通过 → revoked（撤销）；被点名方提交反证 → appealing（申诉中）→ 复核后降级 / 撤销 / 转入观察名单；revoked 亦可由超期未补证据自动触发。对外展示的四级榜单（红榜 / 观察名单 / 灰名单 / 黑名单）由上述状态枚举映射得到。

各状态判定标准

进入各状态所需满足的最低条件

待考证（gray_unverified）

  • 有明确涉嫌主体、有具体涉嫌行为描述、至少一项线索来源，但尚未提交可核验证据。
  • 对外统一标注「未证实」，限制传播；不得仅凭传闻、匿名爆料或「听说」直接定性。

待自证（gray_self_proof）

  • 已上传至少一项可核验证据、证据能指向具体主体与行为、提交人声明来源合法、平台或第三方开始核验。
  • 强制字段齐全：涉嫌主体 / 涉嫌行为 / 证据类型 / 证据来源 / 可信度 / 时间线 / 风险等级 / 核验计划。

转黑名单（blacklisted）

  • 须满足至少一项：生效刑事 / 民事判决、行政处罚决定、权利人公开维权公告且有佐证、两家以上独立第三方交叉印证、平台完成代码 / 授权 / 合同 / 销售链路独立核验。
  • 必须标注处罚国家 / 地区与来源链接；国别信息缺失的条目不得进入黑名单；境外判决不直接等同于中国法律结论。

数据字段设计

每个条目的统一字段、国别与实体类型、场景扩展字段

通用字段

字段 类型 说明
id string 条目唯一标识
name string 主体名称（企业实体或开源项目 / 软件产品）
industry string 所属行业
scenario enum 场景：open-source / illegal-profit / design / labor
status enum 状态：red / watch / gray_unverified / gray_self_proof / blacklisted / appealing / revoked
summary string 结论摘要
tags string[] 标签数组
evidence array 证据数组，每项含 type / title / url / date
submitted_by / submitted_at string / datetime 提交人与提交时间
verified_by / verified_at string / datetime 核验人与核验时间
appeal_status string 申诉状态
last_updated datetime 最后更新时间

国别与实体类型

字段 类型 说明
country_of_incorporation string 注册地（ISO 3166-1 alpha-2）
operating_regions string[] 实际运营地区
headquarters string 总部所在地
entity_type enum 实体类型：parent / subsidiary / branch / project
parent_company / subsidiaries string / string[] 母公司与子公司列表；母公司违法不自动连坐子公司，子公司 / 分公司独立违法单独建条目

作息合规扩展字段

字段 类型 说明
work_hours string 标准作息（如 09:00–18:00）
work_time_system enum 工时制度：standard / comprehensive / flexible
approved_special_hours boolean 特殊工时是否经人社部门审批
overtime_rule string 加班规则与月加班上限核查记录
monthly_overtime_hours number 月加班时长（对照法定 36 小时上限）
penalty object 处罚对象：authority / country / date / fine / affected_employees
