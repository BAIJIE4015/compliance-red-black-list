审核、申诉与防滥用

准入门槛、申诉流程与防滥用规则 —— 收录有证据门槛，申诉有明确通道，状态可回退

黑名单准入

正式列入黑名单必须满足的证据门槛

  • 司法与行政文书：生效法院判决（刑事 / 民事）或行政处罚决定，须可核验且已生效。
  • 通报与交叉印证：检察 / 监管通报、权利人公开维权公告且有佐证，或两家以上独立第三方报告交叉印证。
  • 标注要求：必须注明处罚国家 / 地区与来源链接；国别信息缺失的条目不得进入黑名单。

灰名单准入

进入「待考证 / 待自证」的证据要求与强制字段

  • 准入条件：至少提交一项可核验证据，条目统一标注「未证实」；不得仅凭传闻、匿名爆料或「听说」直接定性。
  • 强制字段：涉嫌主体 / 涉嫌行为 / 证据类型 / 证据来源 / 可信度 / 时间线 / 风险等级 / 核验计划，缺项不予受理。
  • 禁止事项：匿名线索默认不进入待自证；证据不足的线索仅可停留在「待考证」并限制传播。

申诉流程

被收录主体提交反证材料的完整路径

提交反证材料（appeals/ 模板） → 14 天内复核 → 降级 / 撤销 / 转入观察名单

复核期间条目状态转为 appealing（申诉中）并加注提示；核验通过后回写结论与状态流转记录，全程可追溯。

反证材料类型

  • 司法与澄清类：判决书 / 裁定书、行政机关撤销或变更决定、官方澄清声明等。
  • 过程与审计类：独立设计 / 研发过程证据（设计稿、版本迭代、代码图纸原型）、用工合规审批文件、第三方审计报告等。

申诉模板

申诉模板位于仓库 appeals/ 目录，按模板填写主体信息、涉及条目、反证材料清单与联系方式后提交。材料不全将一次性告知补正；复核完成后，核验结论、降级 / 撤销决定与依据同步回条目状态流转记录。

防滥用规则

防止恶意举报与证据滥用的约束条款

  • 禁止只写「疑似 / 听说」而无来源的举报，此类线索不予受理。
  • 匿名线索默认不进入待自证阶段，不对外展示为可核验证据。
  • 超期未补充证据的条目自动降级或撤销，不无限期挂网。
  • 伪造证据、恶意竞争举报者限制提交权限并记录在案。
